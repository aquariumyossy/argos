## いまのコード

チャットは添付出典への質疑に加え、モデルが対応していれば会話中にインデックスを検索できる。アプリが送信のたびに BM25 で先回り検索することはしない。

入っているもの:

- 独立チャットウィンドウ、ストリーミング、停止、思考の折りたたみ
- SQLite の会話・メッセージ・出典（`llm_threads` / `llm_messages` / `llm_thread_sources`）
- 検索窓・ノートの「チャット」は送信先ピッカー（新しいチャット／既存）。送るとチャットが前面に出る
- 読込前チップ（段落／全文切替・×）。読込済みは回答末尾のバッジ（開くのみ）
- 出典本文は、それを初めて載せた user ターンにだけ付く。後続の質問には二重に付けない。番号は `cite_no`
- テンプレは「要約」「要点」。文字数目安は読込済み本文も数える
- 設定「ローカルLLM」（URL、モデル、思考、コンテキスト目安、システムプロンプト、インデックス検索の件数）
- ツール `search_index` / `read_unit`（最大おおよそ 3 ラウンド）。取得分は `origin=tool` でその回答のバッジへ
- `llmSearchTopK` はツールの件数（1〜8）。`llmPrefetchIndex` は未使用（設定キーを残していても読まない）
- `llm_threads.search_enabled` / `path_prefix` 列はあるが、UI からは触らない

Tantivy スキーマと `files` 表は変えていない。全文切替で同じ path の他段落を外す処理は読込前だけ。戻すときは `unit_body`。

## フェーズ3でやったこと（破棄済み）

送信時 prefetch で既存 `search_query`（BM25）を呼び、ヒットを出典チップへマージする案。モデルはツールを持たず、検索しない。

入れたもの（コードからは削除）:

- チェック「インデックスを検索」（出典空ならオン、添付直後はオフ）
- フォルダスコープ（`list_search_scopes` / 最近のスコープ）
- テンプレ「関連を調べる」（検索オンにするだけ。スコープはユーザーが選ぶ）
- 送信時 top-k（既定4、本文1200文字）、`origin=search` のチップ
- 整形フォローアップ（「続き」「もっと短く」等）は検索スキップ
- 回答末尾 `[[SEARCH_HINTS]]` をパースし、次ターン用の破線チップにする（検索は起動しない）
- システムプロンプトに「自分では検索するな／ヒントのために検索した体で書くな」

既存 DB に `hint_queries` 等の列が残っていても未使用。DROP しなくてよい。

## 使って分かったこと

ユーザーにもモデルにも分かりにくかった。破棄の直接の理由。

1. **検索の主体が二つある**  
   アプリが送信時に BM25 し、モデルには「検索するな」と伝える。ユーザーは「関連を調べる」「インデックスから探して」と頼む。モデルは権限・機能が無いと言い出した（実害: ヒットがチップにあっても「追加資料の検索は行えていません」）。

2. **入力まわりが厚い**  
   出典チップ、次の検索語（破線）、チェック、フォルダ、テンプレ、文字数。ケース1の要約だけしたいときも同じ複雑さになる。

3. **破線チップの意味が読めない**  
   出典ではなく、次の送信の BM25 に足す候補。今すぐ検索しない。説明なしでは実線の出典と区別できない。

4. **「関連を調べる」が検索語になる**  
   テンプレ文面そのものがクエリになり、フォルダを絞っても当たりにくい。後から題名ベースに直したが、根本の「誰が探すか」は残った。

5. **出典が最初の質問にだけ付く**  
   当時の 2.6 の仕様。2ターン目の「関連を調べる」の横に新しいヒットが見えず、モデルが添付と検索結果を結び付けにくい。最終ターンに寄せる案も試したが、prefetch モデル自体の分かりにくさは残る。現行は消費モデル（読んだターンにだけ本文）とツール結果のバッジで置き換えている。

## その後どうしたか

プリフェッチは戻していない。関連調査はツールコーリングに寄せた。入力はメッセージ + 読込前チップ + 送信。フォルダ絞りはツール引数のみ。

検索窓・ノートからはピッカーで新規または既存を選ぶ。生成中の追送は次の送信で読まれる。

フェーズ3専用で消したもの: `src-tauri/src/llm/hints.rs`、`llm_update_thread_search`、チャットの検索チェック／スコープ／ヒント UI、「関連を調べる」。

主戦場: `src/features/chat/*`、`src-tauri/src/llm/{commands,context,grain,mod,tools}.rs`、`src-tauri/src/db/mod.rs`。
