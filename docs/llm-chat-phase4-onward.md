## 前提（いまのコードのうえ）

アシスタント回答は Markdown として描画する（見出し・リスト・表、生 HTML / 画像は出さない）。図は ````mermaid`、選択肢は ````choices`（クリックで入力欄を置換）。要件事実・時系列はテンプレ。書き出しとノート保存はまだ入れない。

会話中のインデックス検索はツール（`search_index` / `read_unit`）が既にある。フェーズ3の prefetch は挟まない:

- 送信のたびにアプリが検索する経路は戻さない
- `[[SEARCH_HINTS]]` は出さない
- ケース2/3の「探して」は現行のツールで足りる範囲がある

## フェーズ4 — 要件事実図と書き出し

目的: 添付出典から図を出し、会話をファイルとノートに戻す。

### 入ったもの（描画）

**Markdown**

- アシスタント本文をノートの「整形」と同じトーンで描画（チャットの見出しはサイズ階層あり）
- `marked` の生 HTML と画像は出さない。リンクは `http(s):` のみ
- 漢字の条文番号は Markdown ブロックだけアラビア数字にする

**選択肢**

- ````choices` の各行がボタン。クリックは入力欄を置換（送信しない）

**Mermaid 図**

- 依存 `mermaid`。描画は `securityLevel: "strict"`。LLM の生 HTML は出さない
- 回答中の ````mermaid` を検出し、図とソースの切替
- フェンスが壊れてもソースは見える
- クレジットタブに mermaid（と marked）のライセンス

**テンプレ（入力欄上）**

- 要件事実: `flowchart LR`（左が請求原因、右へ抗弁・再抗弁）。請求原因はノード1つ。**添付出典にない事実はノードにしない**。ノードに `[n]`
- 時系列: 出典上の出来事だけ
- 既存の「要約」「要点」は残す
- mermaid の書き方はシステムプロンプトに常時載せない（テンプレ、およびユーザーが図を頼んだ回の短いヒントに閉じる）

描画ルールと、参照データ側の未着手は [llm-chat-fact-diagram.md](llm-chat-fact-diagram.md)。

### まだ入れないもの

**Markdown 書き出し**

- ノートの [src/features/notes/exportNoteText.ts](../src/features/notes/exportNoteText.ts) と同じく、保存ダイアログ + `write_text_file`
- 内容: 会話タイトル、日時、使用モデル、添付出典（パス・検索語）、メッセージ。mermaid フェンスは生のまま（他ツールで再描画できるようにする）
- 既定ファイル名はノート書き出しと同様にサニタイズ

**回答をノートへ保存**

- 新規ノート、またはアクティブノートへ。出典はチャット側を書き換えない（ノートは同期しない）

- 図の SVG / PNG 保存（フェーズ5）
- 矛盾抽出専用テンプレ
- 会話タイトルの自動命名
- 送信時 prefetch、専用検索欄、破線ヒント（ツール検索は既にあるので増やさない）

### 描画の完了条件（実装済み）

- ノートまたは検索添付から要件事実図が描画される（フェンス破損時もソースは見える）
- XSS になりうる生 HTML がメッセージに出ない
- mermaid 未出力の通常回答が壊れない
- 回帰: ピッカーで新規／既存、チップの段落／全文切替、ツール検索

検証: 要件事実テンプレ、時系列、mermaid なし回答、巨大な図でウィンドウが落ちないこと。

### 主戦場

`src/features/chat/*`、`package.json`（`mermaid`）、設定のクレジット。インデックス・Outlook COM・スコアリングは触らない。

## フェーズ5 — 将来（未スケジュール）

フェーズ4のあと、利用を見て優先する。

### ツール検索の延長

現行の `search_index` / `read_unit` は残す。フォルダ絞りはツール引数のまま。未知パスへの自動スコープ変更、結果の非表示送信、embedding、会話全体のクエリ書き換えは入れない。専用「インデックスを検索して添付」欄も入力を厚くするので後回し。

`grain=file` の path には段落ヒットを足さない。予算超過は古い `search|tool` の unit から。

### その他

- 会話の Markdown 書き出し、回答のノート保存
- OS からのファイル添付（ドロップ／ピッカー。`grain=file` の出典として並べる）
- 図の SVG / PNG 保存
- 複数ヒットの矛盾抽出テンプレ
- 回答中の語を選んで再検索
- 初回応答後の会話タイトル自動命名
- チャット用ショートカット（既定オフまたは `Ctrl+Alt+L`）
- システムプロンプトの事務所向けプリセット

## フェーズ4でも守るもの

- 出典はメッセージ表に書かない。セットは `llm_thread_sources`。本文は消費した user ターンにだけ載せる
- 生成中の二重送信禁止。中断した部分回答は確定扱いにしない
- 生成中は粒度切替しない
- チャットも `argos-ready` と close→hide
- 失敗時のコンテキスト長メッセージは既存どおり
- 各出荷単位で検索・ノート・設定が回帰すること
