# 検索ポップアップのフォルダスコープとリモート

最終更新: 2026-09-16  
状態: ホストの `/scopes` は実装済み。クライアント（検索ポップアップ）がリモート一覧をマージするのは未着手。

検索ウィンドウ（ポップアップ）のフォルダスコープピッカーに、ホスト側にだけあるフォルダが出ない件。明文化された「出さない仕様」ではなく、一覧のソースがクライアントローカルだけであるため。

関連: [stability-followups.md](stability-followups.md)（Popup の親パス、`search_mode=remote` と mail マージ）

---

## 現状

ピッカーは `list_search_scopes` が **この PC の SQLite `folders` + `files`** から組み立て、フロントが Outlook メールフォルダを足す。

- ルート: 有効な登録フォルダの `effective_public_root`（`public_path` があればそれ、なければ `path`）
- サブフォルダ: `list_file_paths_by_folder` の親ディレクトリ（ルートあたり最大 400）
- クエリあり: `run_search` のヒットで上記一覧を間引くだけ。リモート専用フォルダは増えない
- 空表示: 「設定からフォルダを追加してください」（ローカル設定を指す）

リモート HTTP は `/health` `/search` `/path_matches` `/preview` に加え `GET /scopes` がある。同一 PC のループバック（`127.0.0.1`、Argos 起動中は常時、Bearer 不要）ではこの PC の索引全体とメールフォルダを返す。LAN（`0.0.0.0`、設定オンかつトークンあり）では Bearer 必須で、共有フォルダ以外は出さない。メールは LAN には出さない。

検索そのものはスコープの `path_prefix` をリモートにも渡せる。ヒットの「このフォルダ内で再検索」なら、ピッカーに無くてもホスト側もそのパスで絞れる。ローカルとホストが同じ公開パス（UNC 等）なら、ローカルに出ているフォルダを選ぶとリモートヒットもその配下で絞られる。

---

## 出したいもの

ホストにだけあるフォルダを、リモート／ハイブリッド時のピッカーに出す。メールはリモートに出さない（現行どおり）。

---

## スキーマ

**SQLite / Tantivy の変更は不要。** 索引の再構築も、設定テーブルの列追加も要らない。

直近スコープ（`recent_search_scopes`）はパス文字列の JSON なので、リモートパスもそのまま保存できる。

Tantivy の `folder` フィールドはホストのローカルパス（`C:\…`）のことがある。一覧のソースには使わない。`collect_search_scopes` と同じく SQLite の `folders` / `files`（索引パスは公開パスへ書き換え済み）を使う。

---

## 実装方針（ホスト側は実装済み）

1. リモートサーバに `Db`（と mail 索引・設定・ユーザー辞書）を渡す
2. ホストに `GET /scopes`。`collect_search_scopes` を再利用。LAN ではメールは含めない（ループバックでは `mailfolder:` を足す）
3. クライアントが取得し、`list_search_scopes` でローカル一覧とパス（大小無視）で重複排除 — **未着手**
4. 旧ホストは 404 なら空扱い（`path_matches` と同じ）
5. クエリ連動: リモートスコープを `all` にマージすれば、既存のヒット間引きがほぼ使える

ルートだけ出すなら小さい。サブフォルダまでローカルと同じにするのも関数再利用で足りる。重いのは LAN 転送と、ホストが `files` を辿るコスト。

UI に「リモート」印を付けるかは任意。`SearchScopeRow` に source を足すなら IPC/JSON の拡張であり、DB スキーマではない。

---

## 制約（実装時に残る）

- **ホストが新エンドポイントを持っていないと、クライアントだけ直しても一覧は増えない**
- 公開パス未設定なら、ピッカーにホストの `C:\…` が出て検索はできてもクライアントから開けない（今のリモートと同じ）
- ハイブリッドで同じ UNC を双方が登録していると重複する。マージ必須
- メールフォルダはホストから出さない（`mailfolder:` はローカルのみ）
