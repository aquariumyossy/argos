# Argos v{VERSION}

ローカル文書を一瞬で全文検索する Windows デスクトップアプリです。

## ダウンロード

| ファイル | 説明 |
|----------|------|
| **Argos-Setup-v{VERSION}.exe** | 推奨。ダブルクリックでインストール（管理者権限不要） |
| Argos-v{VERSION}-windows-x64.zip | インストーラ・ポータブル版・INSTALL.txt の一式 |

動作環境: Windows 10 / 11（64bit）

SmartScreen で警告が出る場合は、発行元が未署名のためです。問題なければ「詳細情報」→「実行」で続行できます。

## インストール後の流れ

1. トレイアイコン →「設定を開く」
2. 検索対象フォルダを追加 →「今すぐインデックス」
3. 文字列を選択して `Ctrl+Alt+A` で検索
